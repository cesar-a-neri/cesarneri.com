Notebooks

During my time in the Notebooks team, we reimagined the product with a more modern, collaborative UI. We introduced core features that made it the go-to tool for live documentation, incident analysis, and postmortems for hundreds of organizations. I also designed and implemented components adopted across the whole platform.

Notebooks are collaborative text editors within Datadog that allow users to combine written content with live monitoring data. They’re used to document investigations, postmortems, and runbooks, enabling teams to analyze incidents and share context directly within a single document.

Get Started

A new landing page for organizations new to Notebooks, offering clear entry points through templates for common use cases like postmortems, gamedays, and exploratory investigations. The layout emphasized approachability and actionability, using a fresh, colorful design that later served as a model for onboarding pages across the platform.

List Page

A redesigned Notebooks list page to improve discoverability and onboarding. New filtering options by type and owner made it easier to navigate large volumes of content, while a “Suggested” section highlighted frequently used notebooks and offered guidance for new users. A template gallery was also introduced to help teams quickly start new documents based on common use cases.

Collaborative Interface

We modernized the Notebooks editor with a cleaner interface to support faster collaboration and adoption. Introduced real-time multiplayer editing and commenting—critical features for workflows like postmortems and investigations. Additional enhancements included graph snapshotting, a table of contents, drag-and-drop cell reordering, and improved time mutability controls for working with historical data.

Markdown Editor

Designed and implemented a new Markdown editor component to be used across the platform, offering a flexible alternative to a WYSIWYG editor within engineering constraints. The interface included toggle controls for edit and preview modes, along with inline autocompletion to reduce reliance on Markdown syntax memorization.

Template Variables

Template variables allow users to dynamically filter one or more widgets within a dashboard and create saved views for navigating visualizations via dropdown selections. Usability improvements included clearer controls for selecting all, deselecting all, or isolating a single option. The component was also restyled to make active filters more visible, improving clarity and reducing user error.
